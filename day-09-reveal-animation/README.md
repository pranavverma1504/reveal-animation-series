# MARTION

Personal site for MARTION: an "M" symbol draws itself and fills up while a percentage counts to 100%, then the screen lifts away like a curtain to show the MARTION title over a mountain image.

Built with React, TanStack Start, and Tailwind CSS. The animation uses plain CSS and SVG with no animation libraries.

## Requirements
- Node.js 20 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the address shown in the terminal.

## Production build
```bash
npm run build
```
