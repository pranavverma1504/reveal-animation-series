# Source audit

Retained: original GSAP timeline, all nine tile definitions and shutters, eight supplied images, all referenced CSS-module selectors, seven five-glyph character reels, Bebas Neue, React, TanStack routing/query shell, Vite, TypeScript, Tailwind CSS processing, and Nitro production server adapter.

Removed from the export: unused UI components and packages (Radix, form libraries, charts, icons, carousel, toasts, date utilities), unused hooks/utilities, default favicon and robots template, editor-specific error reporting, tests/tooling not needed to run the application, hosted asset pointers, project metadata, dependencies, generated route tree, caches, and build output. The route tree is regenerated by the router plugin during dev/build.

No shutter/reveal/clear stage, clip path, easing, duration, master cue or image crop/scale was changed. Color tokens are precise OKLCH conversions of the original sRGB colors. Native images duplicate next/image fill positioning. Wordmark cleanup restores its original parent to safely support React unmount/effect replay.

The final hero is new and uses the supplied sky-and-flowers photo (public/images/hero/hero-sky.jpg); the M glyph column is sized to its true width. All production images and the font are local; no secrets are required.
