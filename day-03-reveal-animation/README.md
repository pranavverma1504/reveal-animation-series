# developer — reveal animation

A full-screen editorial portrait reveal built with React and plain CSS.

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build` (output in `dist/`), preview with `npm run preview`.

## Structure

- `src/App.jsx` — markup for the five photo panels and the word
- `src/styles.css` — all animation styles and keyframes
- `src/assets/` — portrait photo and the Archivo Black font
